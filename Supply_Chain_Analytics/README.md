# 🛒 Project 1: Multi-Branch Retail Supply Chain & Revenue Analytics Dashboard

## 📌 Business Overview
This project presents an interactive MIS dashboard designed to monitor and analyze supply chain sales performance, profit margins, and volume across multiple retail regions (North, South, East, West). It enables data-driven decision-making for inventory allocation and regional sales strategies.

---

## 🛠️ Excel Tools & Technical Features
* **KPI Summary Cards:** Automated indicators displaying Total Revenue, Units Sold, Net Profit, and Average Order Value (AOV).
* **Pivot Tables & Charts:** Categorical breakdown of sales by region and product line.
* **Interactive Slicers:** Dynamic filtering by Region and Product Category.
* **Data Presentation:** Gridless design interface formatted for executive reporting.
