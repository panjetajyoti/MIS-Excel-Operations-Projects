# 💰 Project 4: Financial Expense Categorization & Budget Variance Analyzer

## 📌 Business Overview
This project delivers a multi-departmental financial analytics dashboard designed to consolidate category-wise operating expenses, perform Budget vs. Actual Variance analysis, and flag budget slippages across corporate functions.

---

## 🛠️ Excel Tools & Technical Features Demonstrated
* **Text Aggregation & Categorization:** Leveraged `TEXTJOIN` to consolidate multi-line expense descriptions into unified department-level records.
* **Aggregated Budget Tracking:** Formulated dynamic `SUMIFS` and `VLOOKUP` expressions to calculate department-wide actual spend against allocated budgets.
* **Variance & Slippage Alerts:** Designed automated financial metrics computing Variance Amount and Variance % alongside conditional `IF` warnings for over-budget departments.
* **Executive Presentation:** Formatted for finance leadership review with gridless views and visual status indicators.

---

## 📊 Key Highlights & Metrics
* **Total Departments Monitored:** 5 (Marketing, IT, Operations, HR, Sales)
* **Budget Tracking:** Automated tracking of allocated vs. spent capital with instant over-budget flags.
