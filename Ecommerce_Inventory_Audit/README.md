# 📦 Project 3: E-Commerce Customer Order Management & Inventory Audit System

## 📌 Business Overview
This project provides an end-to-end operational dashboard to track multi-status order lifecycles (Pending, Dispatched, Delivered, Returned) and perform automated stock audits to prevent stockouts and manage SKU inventory effectively.

---

## 🛠️ Excel Tools & Technical Features Demonstrated
* **Order Lifecycle Audit:** Aggregated multi-status order metrics using `COUNTIFS` and dynamic array formulas.
* **Return Rate KPI:** Calculated percentage of returned shipments against total orders for quality monitoring.
* **Automated Low-Stock Alerts:** Implemented dynamic `IF` logical statements combined with Conditional Formatting to trigger instant reorder alerts.
* **Data Auditing Interface:** Clean, gridless dashboard layout formatted for e-commerce operations leads.

---

## 📊 Key Highlights & Metrics
* **Total Return Rate:** 25%
* **Stock Alert Engine:** Dynamic visual highlights for SKUs falling below minimum reorder thresholds.
